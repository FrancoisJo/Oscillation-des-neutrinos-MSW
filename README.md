# Oscillation-des-neutrinos-MSW

Jonas François
Université de Strasbourg — 2025/2026

Projet tutoré de Licence 3 — Physique des particules et oscillations de neutrinos.

Simulation numérique des oscillations de neutrinos à trois saveurs dans le cadre du modèle PMNS, avec prise en compte des effets de matière de type MSW avec une densité constante.

Le programme calcule les probabilités de transition et de survie des neutrinos et antineutrinos en fonction du rapport L/E, pour différentes hiérarchies de masse. Il est normalement facile de faire varier les paramètres ou les variables prises en compte afin de déduire de leurs impacts sur l'oscillation des neutrinos dans ce cadre, et d'en extraire les informations pertinentes pour tout utilisateur.

Fonctionnalités : 
  Modèle à trois saveurs ;
  Matrice de mélange PMNS complexe ;
  Effet de matière (MSW) ;
  Neutrinos et antineutrinos ;
  Hiérarchie normale et inversée ;
  Diagonalisation numérique de l’Hamiltonien ;
  Vérification numérique de l’unitarité ;
  Génération automatique des courbes d’oscillation.

Il s'agit seulement d'un code réalisé dans le cadre d'un stage encadré par l'université, il est par conséquent encore largement améliorable, que ce soit sur l'aspect physique comme numérique. 

J'essaierai à l'avenir de prendre en compte les cas où la densité n'est pas constante, le traduire en anglais, davantage subdiviser les tâches, s'intéresser aux modèles à 4 saveurs pour discuter du neutrino stérile, etc.
